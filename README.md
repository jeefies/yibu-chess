# 弈步 0.2.0 安装包

手机浏览器登录 GitHub 账号 `well49112` 后，点击下面的链接下载。

[下载 ARM64 APK（约 83 MiB）](https://github.com/well49112/yibu-chess/raw/refs/heads/apk-downloads/yibu-0.2.0-arm64.apk)

如果浏览器显示文件页面，点击右上角的下载按钮（Download raw file）。最低 Android 8.0，支持 Xiaomi 17 Pro 等 arm64 手机。内置 Stockfish 引擎和权重，运行无需联网。

0.2.0 增加个人 Elo（初始 500）、匹配分数的动态对手、最强不计分模式、新版棋步评级及棋谱删除。可直接覆盖 0.1.x 安装，版本签名保持一致；升级会保留旧棋谱，旧局不补计分。旧版评级可在复盘中点击“整盘深度复评”更新。删除棋谱不撤销已结算的分数。
