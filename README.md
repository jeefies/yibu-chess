# 弈步 0.1.0 安装包

手机浏览器登录 GitHub 账号 `well49112` 后，点击下面的链接下载。

[下载 ARM64 APK（约 83 MiB）](https://github.com/well49112/yibu-chess/raw/refs/heads/apk-downloads/yibu-0.1.0-arm64.apk)

如果浏览器显示文件页面，点击右上角的下载按钮（Download raw file）；不要下载整个源码 ZIP 来安装。

最低 Android 8.0，支持 Xiaomi 17 Pro 等 arm64 手机。下载后点击 APK，按手机提示允许浏览器或文件管理器安装应用。内置 Stockfish 引擎和权重，运行无需联网。

[源码、构建说明和开源许可](https://github.com/well49112/yibu-chess/tree/main) · [版本说明](https://github.com/well49112/yibu-chess/releases/tag/v0.1.0)
