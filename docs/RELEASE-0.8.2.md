# 弈步 0.8.2 · 分析耗时记录

[APK 下载页面](https://github.com/well49112/yibu-chess/blob/apk-downloads/yibu-0.8.2-arm64.apk) · [完整操作与服务端说明](ANALYSIS-TIMING.md)

复评几步后，点顶部信息按钮 → “导出分析耗时”，分享 `yibu-analysis-timings.json`。保持 App 在前台，导出前不要重启。最近 120 次分析与全棋谱解码事件保存在内存中，导出时才写文件。

新增单调时钟分段计时：HTTP 请求、DNS、连接/TLS、响应读取、手机结果处理、保存事务、全部棋谱 JSON 解码和下一帧回调。每次分析携带随机 `X-Request-ID`，朋友可以按相同编号对照服务端日志。可选的 stats 或 Server-Timing 提供搜索、排队、总处理和缓存信息；未提供的数据为 null，缺失帧数据也为 null。

计时继续使用 0.8.1 的 deep/MultiPV 请求和按步保存顺序，用于定位手机约 3 秒与服务端约 0.6 秒之间的耗时。记录不包含 Access Token、请求/响应正文、完整棋谱、SSID 或具体 IP。普通 ACCESS_NETWORK_STATE 权限仅用于记录活动网络类型，不需要运行时授权。

同包名、原个人签名，versionCode 15，可覆盖安装并保留棋谱、Elo 与设置。服务器接口无需先修改，即可使用手机计时；加入服务端计时后能进一步分清网络和排队/搜索开销。
